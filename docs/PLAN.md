# Delivery plan

## Bounded promise

Identify changes in recorded contractual IP rights with exact source evidence.

## Delivered journey

Install -> inspect the synthetic sample -> supply explicit inputs -> deterministic
analysis -> frozen evidence package -> local reviewer correction/assessment ->
fingerprint-bound decision import -> fresh reviewed report and receipt -> verification.

## Implementation sequence

1. Strict schema and deterministic domain engine.
2. Source evidence and explicit uncertainty.
3. Transactional analysis package and guarded review finalisation.
4. Local report with correction controls and exported decisions.
5. Licensed synthetic matter, negative controls and end-to-end tests.
6. Clean wheel install, browser journeys, screenshots, public repository and CI.

No umbrella platform, external model or live connector is required. Future extensions
must preserve this independent journey and retain original evidence and schema versions.
