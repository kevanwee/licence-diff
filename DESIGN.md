# Local evidence review

Mode: Operate / Read. A paper-like report with readable source quotations, before/after
comparisons, explicit classification and assessment controls. Quiet blue ink, light
surfaces and native form controls support sustained document review. Georgia titles;
system sans body; monospace only for structured records and fingerprints. All content
is available offline. Narrow screens stack comparisons; keyboard focus is visible.
The first viewport states the matter, review status, synthetic disclosure and scope.

This is a new report surface built code-first for the user's autonomous product brief.
No artwork or external typography is required for this operating context.
