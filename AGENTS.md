# Engineering boundaries

This is an independent product. Do not depend on sibling repositories or global skills.
Preserve original inputs and findings. Corrections are review overlays or new input
versions; never silently replace evidence. No legal-compliance or survey-certification
claims. Synthetic data and decisions must be labelled. New schema versions are explicit.
Run pytest and Ruff; test installable wheels and the documented full journey. Avoid
committing real matters, credentials, absolute home paths or generated review decisions.
